# Preferências de trabalho neste projeto

- Leia apenas os arquivos necessários para a tarefa. Assim que encontrar a informação necessária, pare de buscar e não explore arquivos ou diretórios sem motivo.
- Prefira buscas de texto específicas e trechos relevantes a despejar arquivos completos ou grandes saídas no contexto.
- Não rode scripts, testes ou verificações por iniciativa própria; faça isso quando o usuário pedir ou quando forem necessários para concluir a tarefa autorizada.
- Ao executar comandos que possam produzir muita saída, evite opções verbose e redirecione stdout e stderr para um arquivo temporário. Confira primeiro apenas o código de saída. Se houver falha, use buscas de texto no arquivo temporário para localizar as mensagens relevantes, sem ler a saída inteira.
- Evite repetir buscas e leituras já feitas. Agrupe operações independentes quando isso reduzir chamadas sem aumentar ruído.
- Mantenha atualizações de progresso e resumos finais concisos; registre decisões e pendências importantes para evitar reexaminar trabalho concluído.
